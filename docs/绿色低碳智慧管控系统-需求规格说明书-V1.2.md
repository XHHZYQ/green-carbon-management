## 1 引言

### 1.1 编写目的

本文档定义"绿色低碳智慧管控系统"（以下简称"本系统"）的总体需求、功能需求与非功能需求，作为需求确认、测试与验收的依据。

### 1.2 项目背景

园区、企业办公楼等场所内存在大量智能化电气设备与办公设备，普遍存在"家底不清、能耗不明、管控不力、碳排不算"的问题：设备种类多、分布散，缺少统一台账；能耗数据分散，浪费点难以发现；设备依靠人工现场操作，无法远程管控；碳排放缺乏核算数据基础。本系统面向上述场景，提供设备接入、设备台账、远程控制、实时监控、能耗监测、费用管理、碳排放核算、节能考核、告警运维、报表与数据可视化能力，实现"**省能、省钱、合规、安全**"。

### 1.3 术语与缩略语

| 术语 | 说明 |
| --- | --- |
| 驾驶舱 | 系统首页的数据大屏，集中展示关键指标与图表，只读总览 |
| 台账 | 设备的档案清单，以表格登记设备关键信息，支持检索与维护 |
| 设备接入 | 登记设备、配置通信连接参数并使其"上线"的过程 |
| 测点 | 设备上可被采集的数据点，如电压、电流、温度、累计电量 |
| 控制点 | 设备上可被下发指令的操作项，如电源开关、温度设定、运行模式 |
| 组态图 | 以图形化元件与连线还原设备结构并绑定实时数据的监控画面 |
| 场景 | 一组跨多台设备的控制动作集合，可一键或定时执行 |
| 联动策略 | 以"条件 → 动作"形式定义的自动触发规则 |
| 碳因子 | 单位能耗对应的二氧化碳排放量系数，用于能耗换算碳排 |
| 范围一/二/三 | 温室气体核算分类：直接排放 / 外购能源间接排放 / 其他间接排放 |
| 定额 | 对区域或分项设定的能耗控制目标值，用于节能考核 |
| 峰平谷 | 分时电价的三个时段类型：高峰、平段、低谷（含尖峰） |

### 1.4 文档范围与读者对象

本文档覆盖本系统 V1.0 的功能与非功能需求，不涉及实现细节；读者为产品、测试与验收人员。

## 2 总体描述

### 2.1 系统目标

1. 统一接入并管理园区/企业的智能电气设备与办公设备，形成清晰的设备台账；
2. 实时监控设备运行状态，支持组态图与区域平面图展示；
3. 实时掌握能耗情况，支持分项、分区、分时统计与对比分析；
4. 支持设备的远程控制、定时控制与场景联动，实现"看得见、控得住"；
5. 按分时电价核算用电费用，支撑用能成本管理；
6. 基于能耗数据完成碳排放核算并输出碳排报告；
7. 设定能耗定额并进行节能考核，推动持续节能；
8. 对设备异常形成告警、工单与消息通知的闭环；
9. 通过报表中心与数据驾驶舱集中呈现系统运行全貌。

### 2.2 目标用户与角色

| 角色 | 说明 | 主要权限 |
| --- | --- | --- |
| 系统管理员 | 系统最高管理者 | 全部功能，含用户、角色、设备接入与基础配置 |
| 能源管理员 | 负责能耗、费用与碳排管理 | 能耗管理、电价与费用、碳排放管理、节能考核、报表 |
| 运维人员 | 负责设备与告警处理 | 设备管理、设备控制、场景策略、告警与工单 |
| 普通用户 | 只读查看 | 驾驶舱、台账、报表的只读查看 |

### 2.3 运行环境

主流浏览器（Chrome / Edge 等），分辨率 ≥ 1366×768，驾驶舱建议大屏；服务端支持 Linux / Windows；内网部署。

### 2.4 设计原则与约束

1. **简洁优先**：以"覆盖完整、实现简洁"为原则，不做复杂策略引擎与多租户。
2. **数据模拟**：V1.0 全部设备数据、能耗数据、通知发送由系统内置生成，**不接入任何真实硬件与外部通道**。
3. **接口预留**：设备接入与设备控制按真实系统的形态设计（协议、连接参数、指令模型），保证后续可平滑对接真实设备。
4. **可视化优先**：驾驶舱、组态图与图表为重点，界面需清晰美观，适配大屏展示。

### 2.5 总体功能结构

业务主线：

```
设备接入 → 设备台账/测点 → 实时监控 → 数据驾驶舱 → 设备控制/场景联动 → 能耗管理
        → 电价与费用 → 碳排放管理 → 节能与定额考核 → 告警与工单 → 消息通知 → 报表中心
                                                              ↑
                                     登录与权限 / 基础配置中心 / 系统管理（贯穿全局）
```

| 序号 | 模块 | 说明 |
| --- | --- | --- |
| 1 | 登录与权限 | 系统入口，用户认证与访问控制 |
| 2 | 数据驾驶舱 | 首页数据大屏，关键指标总览 |
| 3 | 实时监控 | 设备组态图、区域平面图与实时数据刷新 |
| 4 | 设备接入 | 添加设备、配置协议与连接参数、设备上线 |
| 5 | 测点与数据管理 | 测点定义、采集配置、历史数据与数据补录 |
| 6 | 设备管理（台账） | 设备台账、详情、区域分组 |
| 7 | 设备控制 | 单设备控制、批量控制、定时控制、控制记录 |
| 8 | 场景与联动策略 | 场景一键/定时执行、条件联动规则 |
| 9 | 能耗管理 | 能耗总览、能耗分析、分项计量 |
| 10 | 电价与费用管理 | 峰平谷电价方案、计费规则与费用统计 |
| 11 | 碳排放管理 | 碳排总览、碳排放核算、碳报告 |
| 12 | 节能管理与定额考核 | 能耗定额、执行监控、节能指标与考核 |
| 13 | 告警与工单 | 告警中心、工单管理 |
| 14 | 消息通知中心 | 通知渠道/模板/规则与消息记录 |
| 15 | 报表中心 | 报表模板、周期报表、导出与订阅 |
| 16 | 基础配置中心 | 数据字典、碳因子、设备类型/协议等基础数据 |
| 17 | 系统管理 | 用户管理、角色权限、操作日志 |

## 3 功能需求

> 功能点编号规则为 `FR-模块号-序号`，模块号与 2.5 总体功能结构中的模块序号一致。

### 3.1 登录与权限

提供用户登录、退出与基于角色的访问控制。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-1-01 | 用户登录 | 输入用户名、密码，校验通过后进入系统 |
| FR-1-02 | 图形验证码 | 登录页展示验证码，防止暴力登录 |
| FR-1-03 | 退出登录 | 清除登录状态并返回登录页 |
| FR-1-04 | 修改密码 | 用户可修改本人密码 |
| FR-1-05 | 菜单与权限控制 | 按角色动态展示菜单，无权限页面不可访问 |
| FR-1-06 | 登录日志 | 记录登录账号、时间、IP、结果 |

**业务规则**：用户名或密码错误统一提示；连续失败 5 次锁定账号 10 分钟；未登录访问业务页面自动跳转登录页。

### 3.2 数据驾驶舱

系统首页的数据大屏，集中展示关键指标与可视化图表，为只读总览页。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-2-01 | 关键指标卡片 | 在线设备数、设备总数、今日能耗、今日碳排放、未处理告警数 |
| FR-2-02 | 能耗趋势图 | 近 7/30 天能耗趋势折线图 |
| FR-2-03 | 分项能耗占比 | 照明/空调/动力/办公等分项占比 |
| FR-2-04 | 区域能耗排名 | 按区域统计能耗并降序排名 |
| FR-2-05 | 碳排放概览 | 累计碳排放量与目标完成度 |
| FR-2-06 | 设备状态分布 | 在线/离线/告警设备数量分布 |
| FR-2-07 | 实时告警滚动 | 展示最新告警信息 |
| FR-2-08 | 大屏模式 | 支持全屏大屏展示，自动刷新 |
| FR-2-09 | 费用与定额概览 | 本月电费、定额完成率等关键指标 |

**业务规则**：数据默认每 30 秒自动刷新；驾驶舱为只读页，不提供控制与编辑入口。

### 3.3 实时监控

以组态图与区域平面图的形式集中呈现设备的实时运行数据，支持秒级刷新。V1.0 数据为**模拟生成**。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-3-01 | 实时数据卡片 | 集中展示所选设备的实时测点值、单位与更新时间 |
| FR-3-02 | 设备组态图 | 以图形化元件与连线还原设备结构并绑定实时数据 |
| FR-3-03 | 区域平面图 | 在区域平面图上定位设备并展示其实时状态 |
| FR-3-04 | 实时曲线 | 以曲线形式展示测点近一段时间的实时变化趋势 |
| FR-3-05 | 秒级自动刷新 | 支持按 1~5 秒间隔自动刷新实时数据 |
| FR-3-06 | 组态编辑 | 支持拖拽元件、绑定测点并保存组态图 |
| FR-3-07 | 快照导出 | 将当前监控画面导出为图片快照 |
| FR-3-08 | 设备定位联动 | 从平面图点击设备跳转至该设备的实时详情 |

**业务规则**：实时数据来源于测点采集（V1.0 为模拟生成）；组态图与平面图以只读展示为主，编辑需相应权限；刷新间隔可配置。

### 3.4 设备接入

登记设备、配置通信协议与连接参数，并使其"上线"。V1.0 中接入过程为**模拟**，参数结构按真实设备设计。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-4-01 | 添加设备 | 手工录入单台设备的基础信息、协议与连接参数 |
| FR-4-02 | 接入向导 | 分步接入：选设备类型 → 选协议 → 填连接参数 → 测试连接 → 上线 |
| FR-4-03 | 批量导入 | 下载模板批量导入设备清单，导入前校验并反馈错误行 |
| FR-4-04 | 测试连接 | 按当前连接参数发起连通性测试，返回成功/失败与耗时 |
| FR-4-05 | 设备上线/下线 | 控制设备启用状态，上线后可被采集与控制 |
| FR-4-06 | 接入记录 | 记录接入/修改/上下线操作的时间、操作人与结果 |
| FR-4-07 | 连接参数校验 | 对必填项、数值范围、IP/端口格式进行校验 |

**业务规则**：设备编号全局唯一；测试连接失败不允许直接上线；"测试连接"与"上线"在 V1.0 中为模拟结果。设备类型、协议、连接参数详见第 4 章。

### 3.5 测点与数据管理

定义与维护设备测点（数据点），管理采集任务与历史采集数据。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-5-01 | 测点定义 | 为设备新增/编辑测点，配置名称、编码、数据类型、单位、量程 |
| FR-5-02 | 测点模板 | 按设备类型定义标准测点模板，接入设备时套用 |
| FR-5-03 | 采集任务配置 | 配置采集周期、采集方式（模拟/接口）与采集范围 |
| FR-5-04 | 历史数据查询 | 按设备/测点/时间范围查询历史采集数据 |
| FR-5-05 | 数据补录 | 对缺失或异常数据手工补录并标注来源 |
| FR-5-06 | 数据质量标记 | 对数据打质量标记（正常/可疑/缺失/人工补录） |
| FR-5-07 | 数据导出 | 按查询条件导出历史数据 |

**业务规则**：测点编码在同一设备内唯一；历史数据为只读，补录与质量标记需留痕；V1.0 采集数据由系统模拟生成。

### 3.6 设备管理（台账）

以台账形式集中管理全部设备档案。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-6-01 | 设备台账列表 | 表格展示设备编号、名称、类型、区域、状态、接入时间等，支持分页 |
| FR-6-02 | 查询与筛选 | 按关键字、设备类型、区域、状态筛选 |
| FR-6-03 | 设备详情 | 查看基础信息、连接参数、测点、控制点、最近数据、控制记录 |
| FR-6-04 | 编辑设备 | 修改设备基础信息与连接参数 |
| FR-6-05 | 删除设备 | 删除设备（需二次确认，存在关联数据时提示） |
| FR-6-06 | 区域分组管理 | 维护区域/分组树，支持设备归属调整 |
| FR-6-07 | 设备导出 | 按当前筛选条件导出设备台账 |

**业务规则**：设备状态分为在线、离线、告警、停用；删除需二次确认，已被控制任务、场景或告警关联的设备需先解除关联。

### 3.7 设备控制

对设备下发控制指令，实现远程与定时控制。V1.0 为**模拟下发**，指令模型与状态流转按真实系统设计。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-7-01 | 控制面板 | 选择设备后展示其可控点并进行设置 |
| FR-7-02 | 单设备控制 | 对单台设备下发控制指令 |
| FR-7-03 | 批量控制 | 按区域或设备类型批量下发同类控制指令 |
| FR-7-04 | 定时控制 | 创建定时任务，在指定时间自动执行指定控制指令 |
| FR-7-05 | 二次确认 | 危险控制（分合闸、断电、大批量控制）需二次确认 |
| FR-7-06 | 控制结果反馈 | 展示下发中/成功/失败/超时状态与失败原因 |
| FR-7-07 | 控制记录 | 记录操作人、时间、目标设备、控制点、下发值、执行结果 |
| FR-7-08 | 告警联动控制 | 在告警详情中支持"一键控制"（如过载告警 → 远程断电） |

**业务规则**：仅具控制权限的角色可下发指令；批量控制需先提示受影响设备数量；所有控制操作必须留痕且不可删除。控制点、指令模型与下发流程详见第 4 章。

### 3.8 场景与联动策略

将多台设备的控制动作组合为场景，并通过规则实现条件触发的自动联动。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-8-01 | 场景管理 | 新建/编辑/删除场景，场景包含一组设备控制动作 |
| FR-8-02 | 场景动作 | 为一个场景配置多台设备的控制动作（设备 + 控制点 + 目标值） |
| FR-8-03 | 一键执行 | 一键执行场景，批量下发其全部控制动作 |
| FR-8-04 | 定时执行 | 为场景配置定时执行计划（执行时间/重复周期） |
| FR-8-05 | 联动规则 | 配置"条件 → 动作"规则（如某测点超限 → 执行场景或控制指令） |
| FR-8-06 | 执行记录 | 记录场景与联动规则的执行时间、结果与触发来源 |
| FR-8-07 | 场景启停 | 启用/停用场景或联动规则 |

**业务规则**：场景执行按动作逐条下发，任一动作失败不影响其余动作；联动规则命中后自动执行并留痕；危险动作沿用设备控制的二次确认规则。

### 3.9 能耗管理

管理设备实际消耗的能量（电、水、气），以物理量为单位。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-9-01 | 能耗总览 | 总能耗、各能源类型用量、同比环比 |
| FR-9-02 | 能耗分析 | 按时间与维度（区域/设备/分项）查看趋势与对比 |
| FR-9-03 | 分项计量 | 按照明、空调、动力、办公等分项统计能耗与占比 |
| FR-9-04 | 峰谷分析 | 按峰、平、谷时段统计电量与电费 |
| FR-9-05 | 能耗排名 | 按区域或设备对能耗进行排名 |
| FR-9-06 | 能耗成本 | 按电价规则折算能耗费用 |
| FR-9-07 | 能耗导出 | 导出能耗明细与统计报表 |

**业务规则**：能耗单位电量 kWh、水量 t、燃气量 m³；数据来源于设备测点采集（V1.0 为模拟生成）；支持按分项、区域、设备多维度交叉统计。

### 3.10 电价与费用管理

维护电价方案（峰平谷）并按用电量折算费用，支持费用统计与分析。

| 编号 | 功能点 | 说明 |

## 4 设备接入与设备控制 专项说明

> 本章为重点章节。虽然 V1.0 的设备接入与控制均为模拟实现，但接口形态、参数结构与指令模型均按真实系统设计，以保证界面完整性与后续可扩展性。

### 4.1 设备类型分类

| 分类 | 设备类型 | 典型测点 | 典型控制点 |
| --- | --- | --- | --- |
| 计量类 | 智能电表 | 电压、电流、有功功率、累计电量 | — |
| 计量类 | 智能水表 | 流量、累计水量 | — |
| 计量类 | 燃气表 | 流量、累计气量 | — |
| 暖通类 | 中央空调 | 运行状态、温度、功率 | 电源开关、温度设定、运行模式、风速 |
| 暖通类 | 新风机组 | 运行状态、CO₂ 浓度 | 电源开关、风速 |
| 照明类 | 照明回路 | 开关状态、功率 | 电源开关、亮度 |
| 电气类 | 智能开关/插座 | 开关状态、功率 | 电源开关 |
| 电气类 | 配电柜/断路器 | 电压、电流、温度 | 合闸、分闸 |
| 电气类 | UPS | 剩余电量、负载率 | — |
| 新能源 | 光伏逆变器 | 发电功率、累计发电量 | 启停 |
| 新能源 | 储能设备 | SOC、充放电功率 | 启停、充放电模式 |

| 办公类 | 打印机/复印机 | 运行状态、耗材余量 | 开关（待机/唤醒） |
| 办公类 | 电脑/显示器 | 开关状态、功耗 | 电源开关 |
| 办公类 | 投影仪 | 开关状态 | 电源开关 |
| 环境类 | 温湿度传感器 | 温度、湿度 | — |
| 环境类 | 空气质量传感器 | CO₂、PM2.5 | — |

### 4.2 支持的通信协议

| 协议 | 适用设备 | 主要连接参数 |
| --- | --- | --- |
| Modbus RTU | 串口类设备（电表、传感器） | 串口号、波特率、数据位、停止位、校验位、从站地址 |
| Modbus TCP | 网口类设备 | IP 地址、端口、从站地址 |
| BACnet | 楼宇自控设备（空调、新风） | IP 地址、端口、设备实例号、对象实例号 |
| MQTT | 物联网设备 | Broker 地址、端口、Topic、ClientId、用户名、密码 |
| HTTP/REST | 第三方设备或平台 | 接口地址、鉴权方式、Token、请求参数 |
| DL/T 645 | 电力行业电表 | 串口参数、表地址 |
| OPC UA | 工业类设备 | 服务地址、节点 ID |

### 4.3 连接参数定义

**通用参数**：设备编号（必填、唯一）、设备名称（必填）、设备类型（必填）、所属区域（必填）、安装位置、通信协议（必填）。

**通信参数（按协议动态展示）**：

| 参数 | 适用协议 | 说明 |
| --- | --- | --- |
| IP 地址 / 主机 | Modbus TCP、BACnet、HTTP、OPC UA | 设备或网关地址 |
| 端口 | Modbus TCP、BACnet、MQTT、HTTP | 通信端口 |
| 串口号 | Modbus RTU、DL/T 645 | 物理串口标识 |
| 波特率 / 数据位 / 停止位 / 校验位 | Modbus RTU、DL/T 645 | 串口通信参数 |
| 从站地址 / 表地址 | Modbus、DL/T 645 | 设备从站编号 |
| 设备实例号 / 对象实例 | BACnet | 楼宇自控寻址 |
| Broker 地址 / Topic / ClientId / 用户名 / 密码 | MQTT | 消息接入参数 |
| 接口地址 / Token | HTTP/REST | 第三方接口参数 |
| 节点 ID | OPC UA | 数据节点标识 |

**采集参数**：采集周期、心跳周期、超时时间、重试次数、启用状态。

### 4.4 设备接入流程

```
① 选择设备类型 → ② 选择通信协议 → ③ 填写连接参数 → ④ 测试连接（模拟） → ⑤ 保存并上线 → ⑥ 生成接入记录
```

| 步骤 | 说明 |
| --- | --- |
| ① 选择设备类型 | 从设备类型库中选择，决定后续测点与控制点 |
| ② 选择通信协议 | 选择协议后，表单动态展示对应的连接参数 |
| ③ 填写连接参数 | 填写基础信息、通信参数、采集参数，前端校验 |
| ④ 测试连接 | 按参数发起连通性测试，返回成功/失败与耗时 |
| ⑤ 保存并上线 | 保存设备并使设备状态为"在线" |
| ⑥ 生成接入记录 | 记录本次接入操作 |

**校验规则**：设备编号唯一且非空；IP 格式合法；端口范围 1~65535；数值型参数在允许范围内；测试连接未通过时不得上线。

### 4.5 设备控制点定义

| 控制点 | 类型 | 取值范围 | 适用设备 | 说明 |
| --- | --- | --- | --- | --- |
| power | 枚举 | on / off | 空调、照明、插座、办公设备 | 电源开关 |
| mode | 枚举 | cool / heat / fan / auto | 空调、新风 | 运行模式 |
| temperature | 数值 | 16 ~ 30 | 空调 | 设定温度（℃） |
| fanSpeed | 枚举 | low / mid / high / auto | 空调、新风 | 风速 |
| brightness | 数值 | 0 ~ 100 | 照明 | 亮度（%） |
| powerLimit | 数值 | 0 ~ 额定功率 | 充电桩、配电 | 功率上限 |
| switch | 枚举 | open / close | 断路器、配电柜 | 合闸 / 分闸 |
| chargeMode | 枚举 | charge / discharge / idle | 储能 | 充放电模式 |

### 4.6 控制指令模型与下发流程

**指令模型**：指令编号、目标设备、控制点、目标值、优先级（普通/紧急）、执行方式（立即/定时）、定时执行时间、超时时间、是否需要二次确认、操作人、下发时间。

**下发流程**：

```
① 选择设备 → ② 选择控制点 → ③ 设置目标值 → ④ 二次确认（危险/批量） → ⑤ 下发指令 → ⑥ 等待设备响应 → ⑦ 更新状态并记录
```

### 4.7 控制结果与状态

| 状态 | 说明 |
| --- | --- |
| 待下发 | 指令已创建，尚未发出 |
| 下发中 | 指令已发出，等待设备响应 |
| 执行成功 | 设备返回成功 |
| 执行失败 | 设备返回失败，记录失败原因 |
| 超时 | 超过超时时间未收到响应 |

**控制安全规则**：控制需具备相应权限，普通用户不可下发指令；危险控制点（分闸、断电、功率上限变更）需二次确认且需高级权限；批量控制需明确提示受影响设备数量与范围；所有控制指令必须留痕，控制记录不可删除。

### 4.8 模拟实现约定

| 环节 | 模拟方式 |
| --- | --- |
| 测试连接 | 按预设规则返回成功（如参数完整即成功），并返回模拟耗时 |
| 设备上线 | 将设备状态置为"在线" |
| 数据采集 | 按设备类型定时生成符合量纲与量级范围的模拟测点数据 |
| 控制下发 | 生成指令记录，延时后返回"执行成功"并同步更新设备状态 |
| 告警产生 | 按告警规则对模拟数据判定，命中即生成告警 |
| 通信超时 | 可配置一定比例模拟超时/失败，用于演示异常场景 |
| 消息通知 | 邮件、短信按模拟方式发送，仅记录发送记录 |
